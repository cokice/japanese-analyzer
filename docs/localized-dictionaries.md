# 按界面语言显示词典解释

实现分支：`feat/localized-dictionary-explanations`。日期：2026-10-16。此文更新原有[中文词典设计](./chinese-dictionary-design.md)；本次新增繁体转换与韩文解释，中文维基词典仍留作后续独立来源。

## 用户行为

| 界面语言 | 默认解释 | 核对与补充 |
| --- | --- | --- |
| 简体中文 | Jitendex 中文社区版，持续标注「社区机器译文」 | 英文原文折叠；可主动使用当前模型翻译 |
| 繁体中文 | 同一中文来源经 OpenCC `cn→tw` 转换，增加「简转繁」 | 日语词形、读音、例句、写法表不转换；保守保留日语引号及混合假名表达 |
| English | 原有完整英文 JMdict | 不显示无意义的英文翻译按钮 |
| 한국어 | 韩文维基词典日语词条，标注词典原文 | 缺少匹配时保留英文与主动 AI 翻译 |

统一名称为「词典解释」，其中分为「内置解释」「英文原文」「AI 翻译」。内置解释无须模型或 Key，不发起模型请求。默认显示首个适用块的前五条解释，完整内容、例句、表格与图片在「例句与完整解释」展开。其他适用写法／读音的块单独折叠。外部查询保持为同级独立区域；短语、句子与阅读组不会新增词典查询。

社区译文与当前模型译文分开。AI 只翻译用户已展开的英文解释，最多十条；成功结果按原文来源与版本、词条、实际输入、语言及模型缓存。不同词典的编号不互相对应。切换词语、语言或模型时取消旧任务；切回同一语言可复用本次会话的词典缓存。错误／回退／本地补充不可用结果不写入成功缓存。

## 数据与关联

版本、下载 URL、SHA-256、数据日期和转换器版本固定在 `dictionary.locales.lock.json`。

- 中文：`greyindex/jitendex-yomitan-zh` 的完整 `v2026.08.11-zh.4` 包，发布 2026-09-27，上游 2026-08-11。与当前英文版本关联时，同时核对正 JMdict ID、词形、读音及允许组合。非正 ID 重定向与不兼容变体不猜测挂接；中文块拥有内容摘要生成的独立 ID。
- 韩文：Kaikki 的韩文维基词典原始提取，提取 2026-10-15，Wikimedia dump 日期 2026-10-01。只保留 `lang_code=ja` 的源记录。Kaikki URL 会轮换，因此把不足 1 MB 的完整日语记录切片固定到 `scripts/dictionary/sources/ko-ja.jsonl.gz`，同时记录原始下载摘要。旧提交的构建不依赖该 URL 仍返回旧内容。
- 韩文无可靠 JMdict 序号：按词形检索候选，有明确假名读音时进一步过滤。只有唯一候选才挂接；不使用 IPA 或模型猜测同形词。未提供读音的块只声明适用词形，不宣称义项或读音级对应。
- 当前检索仍以英文索引分页、排序，补充数据不新增搜索结果。没有英文记录的本地化词条、中文反查、中文维基词典均不在本次范围内。

固定转换报告见 [dictionary-coverage.json](./dictionary-coverage.json)：中文 435,448 行中排除 138,529 行非正 ID 记录、10,037 行不兼容形式，匹配 210,936 个英文词条；韩文切片 13,633 行，挂接 8,548 个英文词条，2,954 条有解释但有歧义或找不到候选，其余行没有可展示解释。数量衡量可关联性，不代表人工校订覆盖或语义准确率。

## 安全、缓存与故障

中文 ZIP 不解压任意路径：限制成员数量、单文件及总解压大小；只读取约定成员，验证完整包 SHA。富文本转换为应用拥有的节点树，未知节点阻断转换。上游 CSS、事件属性和脚本不执行；链接仅限 HTTP(S)。保留意义相关的读音、列表、注释、例句、表格及来源。

249 张资源按 SHA-256 命名：原 AVIF 插图保留，48 张静态字形 SVG 经受限检查后转 PNG，SVG 不发送到浏览器。`GET /api/dictionary/assets/[id]` 复用会话认证，校验清单成员及文件摘要，固定图片 MIME，并禁止内容嗅探。字形随主题调整；表格标记由应用渲染并附四语言文字提示。

内置英文及三套语言补充共用一个 32 MiB 解压分片 LRU 和并发读去重表。每套补充按 ID 的 SHA 前两位分 256 桶，总计 768 桶；浏览器只接收当前页及当前语言。补充清单绑定英文档案摘要，英文更新须重新生成关联。补充缺失／损坏返回 `unavailable`，英文仍可查询；有效数据中无匹配才提示暂无解释。HTTP v1 外部结果不按数字 ID 自动关联内置库，未知补充字段不予信任。

最大完整本地化词条 81,622 字节、最大解压桶 1,077,919 字节，未触发独立详情接口门槛（单词条 512 KiB／单桶 16 MiB）。超出时构建直接失败，不能截断内容冒充完整。统计沿用功能名、成功失败、耗时及来源类型，不增加词语、释义或密钥。

## 构建、授权与维护

`npm run dictionary:prepare` 依次准备英文与补充数据，校验有效输出后不重复下载。生产构建继续要求英文快照不超过 30 天；中文／韩文提取或发布日期不超过 90 天，上游日期不超过 180 天。运行时不下载数据，过期的已安装数据仍可离线使用，设置显示日期与更新提示。

Next 文件追踪、standalone、Docker 及桌面服务包含同一 `data/dictionary` 和 `LICENSES`。每周及手动的词典更新工作流更新三种来源、重建关联报告，并提出待审 PR。转换结构或规则变动时必须递增锁文件的 `converterVersion`。源包的含义相关结构变化导致构建失败时，应先扩展转换器并测试，再更新锁文件。

## 验证与已知限制

固定测试覆盖允许组合、同形与假名、源语言过滤、独立编号、繁体转换与日语保留、ZIP／节点／链接限制、共享缓存、图片摘要、不可用降级、外部 ID 隔离、无自动 AI、翻译编号不匹配、模型取消和语言切换缓存。现有句子解析、阅读、撤销及分享测试继续运行。

生产 smoke 在未配置模型 Key 下查询简中、繁中、韩文，保留英文，并获取真实 PNG／AVIF 验证摘要。本机参考：首个默认中文查询约 87 ms，重复约 2 ms；已热身后的语言切换约 3–7 ms。「駅」完整响应约 12–16k 字符。完整补充转换约 16–19 秒，压缩 JSON 合计约 57.3 MB，含资源目录约 61 MiB；这不是各平台安装包最终增量。

中文社区译文仍可能误译，韩文覆盖明显少于英文。本次未完成原设计提出的 300 项人工语义评估，不把自动关联测试当作翻译准确率。macOS／Windows 原生安装包和断网 UI 验收需随各平台发布流程继续完成；本次验证服务端离线读取、standalone 与桌面打包路径，不声称已经发布新安装包。
